🔑 Connect Your Google Account

Work Journal stores all your data in your Google Drive — privately, in a hidden app file only you can access. Nothing is stored on any server or in your browser.

To get started, you need a free Google OAuth Client ID (one-time, ~5 min setup):

  1. Open console.cloud.google.com → create a project (e.g. "Work Journal")
  2. APIs & Services → Library → enable Google Drive API and Gmail API
  3. Credentials → Create → OAuth 2.0 Client ID → type: Web application
  4. Under Authorised JavaScript origins, add:
  5. Copy the Client ID and paste it below
